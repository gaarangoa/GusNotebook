Agent instructions
These settings apply when you start a new agent terminal.

        
Workspaces can add their own instructions in Sessions.

        
How instructions are applied
New agent terminals receive these instructions at launch. Existing terminals keep their original instructions. GusNotebook passes the instructions directly to the agent; it does not create CLAUDE.md or AGENTS.md in your project.

        
Claude permissions and advanced rules
Choose actions to restrict in new Claude terminals. Nothing is blocked by default.
Claude Code enforces these rules. Workspace rules are added to them. Rules match command patterns; they are not a sandbox.
